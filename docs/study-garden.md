# Learning garden proposal

Adds a warmer, lighter study card beneath the unchanged decision brief, with three short chapters about source timing, uncertainty and risk. Existing navigation and data semantics are untouched.

Progress rewards correct knowledge-check responses only, not trading, returns, volume or attendance. All chapters remain available. No streaks, timers, leaderboards, confetti, financial promises, tracking, storage or API calls. Incorrect answers receive an explanation and retry without penalty. Completion explicitly invites a break. Progress is in memory and visibly resets on reload or leaving the overview. Learning does not unlock safeguards.

Uses native radio groups, a labelled progress element, polite feedback, readable light surfaces, keyboard focus styling and responsive stacked cards. No required animation.

This is an isolated draft, not a production release. Actual browser/mobile and interaction QA must be recorded separately. PR #95 remains excluded. Privacy settings and files are untouched.
